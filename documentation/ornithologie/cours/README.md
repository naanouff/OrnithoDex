## Liste — contrôle du 2026-10-14

Les 85 noms scientifiques de la liste PDF sont ceux de [especes.md](../especes.md). Aucune espèce en trop, aucune manquante. Ordres identiques. Noms communs identiques, à deux graphies d’affichage près :

- le PDF colle « collierd’or » ; le référentiel garde « collier d'or » ;
- le référentiel met une capitale initiale au nom commun.

Familles identiques, sauf les quatre cacatoès : le PDF écrit **Cacatuidés**, le référentiel avait `Cacatuides`. Aligné le 2026-10-14 sur le PDF (identité, points de cours `[programme]`, [taxonomie.md](../taxonomie.md)). La graphie `Ploceidae` du PDF est déjà celle du référentiel.

Graphies **conservées** parce qu’elles sont celles de la liste de cours, pas celles de l’arrêté de 2006 : *Lonchura striata domestiqua* (l’arrêté écrit *Lonchura* « *domestica* »), *Agapornis roseicollis* (l’arrêté écrit *roseicolis*), *Gallus gallus domesticus* (l’arrêté écrit les races du coq bankiva *Gallus gallus*).

## Formulaire de fiche — cases et app

Le PDF n’apporte **aucune valeur** à recopier (pas de taille, pas de ration, pas de prix).

| Case du formulaire | Dans l’app |
|--------------------|------------|
| Nom latin, nom commun, ordre, famille, photo | Oui |
| Description | Oui — souvent le statut, pas un texte morphologique du cours |
| Taille, longévité | Oui |
| Poids, « Autres » | Non |
| Granivore / insectivore / frugivore | Non comme cases ; le régime sauvage est un texte |
| Reproduction en milieu naturel, période, nombre d’œufs, couvaison | Non |
| Répartition, habitat naturel | Oui |
| Dimorphisme (visible / non, femelle, mâle) | Un seul texte, pas les cases du formulaire |
| Statut CITES, statut UICN | Oui |
| Alimentation en milieu naturel, comportement général | Oui |
| Comportement intraspécifique / interspécifique | Non séparés |
| Alimentation en captivité, maintien, association | Cases présentes ; contenu = trace de consultation, pas une ration |
| Prix animalerie, prix internet, taille de cage, élevage des jeunes, reproduction en captivité, « ne pas associer » | Non — le formulaire est vide, rien à transcrire |

## Arrêté du 11 août 2006 — espèces du programme

L’annexe ne dit pas « cette espèce du programme est domestique ». Elle nomme des **races ou variétés**. Quarante-six taxons du programme ont une entrée. Le capucin domino (*Lonchura striata*) n’est cité que comme parent du moineau du Japon. Trente-huit taxons du programme sont absents de l’annexe oiseaux.

Graphies de l’arrêté, non recopiées dans l’identité : *Agapornis roseicolis*, *Eryhrura gouldiae*, *Neochemia modesta*, « goutelettes », *Lonchura* « *domestica* ».

### Entrée « variétés » ou « races et variétés » domestiques

*Coturnix chinensis* ; *Gallus gallus* (races et variétés du coq bankiva — le programme nomme *Gallus gallus domesticus*) ; *Columba livia* ; *Streptopelia* « *risoria* », variétés de la tourterelle rose et grise *Streptopelia roseogrisea* ; *Geopelia cuneata* ; *Melopsittacus undulatus* ; *Agapornis roseicollis*, *fischeri*, *personatus* ; *Psittacula krameri manillensis* ; *Nymphicus hollandicus* ; moineau du Japon *Lonchura* « *domestica* » du domino *Lonchura striata* ; *Taeniopygia guttata castanotis* ; *Erythrura gouldiae* ; *Serinus canaria* (dites « canaris »).
