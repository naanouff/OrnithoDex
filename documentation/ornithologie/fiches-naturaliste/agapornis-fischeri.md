## Description

Évalué **Near Threatened** (2021 ; A2bd). Endémique nicheur Tanzanie nord-centrale ; EOO ≈ 206 000 km² ; population estimée ≈ 290 000–1 002 000 individus ; tendance **en diminution** (capture passée, hybridation possible). Face orange, corps vert vif, anneau oculaire blanc, bec orange-rouge.  
*Sources : birdlife-agapornis-fischeri ; adw-agapornis-fischeri.*

## Dimorphisme sexuel

Sexes semblables (plumage).  
*Source : adw-agapornis-fischeri.*

## Habitat d’origine

Bois semi-arides à *Acacia*, *Adansonia*, *Commiphora* (1 100–2 200 m) ; savane à palmiers, cultures, forêt riveraine en saison sèche ; savane sèche (major).  
*Sources : birdlife-agapornis-fischeri ; adw-agapornis-fischeri.*

## Régime alimentaire

Surtout granivore (têtes de graines et sol) ; aussi graines d’*Acacia* en arbre ; fruits (petites figues) ; boit quotidiennement.  
*Sources : birdlife-agapornis-fischeri ; adw-agapornis-fischeri.*

## Comportement

Non migrateur. Groupes serrés (10–20 à plusieurs centaines) ; couples à vie ; hybridation possible avec *A. personatus*.  
*Sources : birdlife-agapornis-fischeri ; adw-agapornis-fischeri.*
