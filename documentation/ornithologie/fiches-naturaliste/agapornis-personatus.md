## Description

Évalué **Least Concern** (2018). Endémique nicheur Tanzanie ; EOO ≈ 226 000 km² ; localement commun ; tendance **stable**. Non migrateur. Elevation typique 1 100–1 800 m.  
*Source : birdlife-agapornis-personatus.*
