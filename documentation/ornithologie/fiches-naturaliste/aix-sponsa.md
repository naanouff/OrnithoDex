## Description

Évalué **Least Concern** (2021). Migrateur complet. Population estimée ≈ 4 600 000 individus matures ; tendance **en augmentation**. Présent notamment Canada, États-Unis, Mexique, Cuba (selon saisons).  
*Source : birdlife-aix-sponsa.*
