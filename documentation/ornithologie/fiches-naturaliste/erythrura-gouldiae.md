## Description

Évalué **Least Concern** (2022). BirdLife / IOC : *Chloebia gouldiae* (syn. *Erythrura gouldiae*). EOO ≈ 1 780 000 km² ; ~5 000–50 000 individus matures (meilleure estimation ~25 000, 2020) ; tendance **stable**. Endémique reproducteur d’Australie (nord). Altitude 0–370 m.  
*Source : birdlife-chloebia-gouldiae.*

## Habitat d’origine

Non migrateur. Bois tropicaux ouverts à sous-bois herbeux ; nidification presque exclusivement dans des cavités d’arbres ; collines rocheuses avec *Eucalyptus* près de points d’eau permanents en saison sèche. Nord de l’Australie.  
*Source : birdlife-chloebia-gouldiae.*

## Régime alimentaire

Surtout graines de graminées toute l’année ; parfois invertébrés.  
*Source : birdlife-chloebia-gouldiae.*

## Comportement

Sédentaire (non migrateur) ; très mobile (déplacements de juvéniles bandés jusqu’à ~200 km) ; niche dans des cavités.  
*Source : birdlife-chloebia-gouldiae.*
