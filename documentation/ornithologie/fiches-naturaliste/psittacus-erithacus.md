## Description

Évalué **Endangered** (2021 ; critères A2bcd+3bcd+4bcd). EOO ≈ 4 460 000 km² ; population globale estimée grossièrement 0,56–12,7 millions d’individus ; tendance **en diminution** (capture pour le commerce, perte d’habitat). Plumage gris à queue rouge distinctive ; ~33 cm, jusqu’à ~407 g. Altitude 0–2 200 m.  
*Sources : birdlife-psittacus-erithacus ; adw-psittacus-erithacus.*

## Dimorphisme sexuel

ADW indique un dimorphisme sexuel possible (sexes colorés/patternés différemment) ; détails du plumage peu marqués chez le jaco.  
*Source : adw-psittacus-erithacus.*

## Habitat d’origine

Non migrateur. Forêts humides de basse altitude et marécageuses (majeurs) ; aussi forêts sèches, mangroves, savane sèche, plantations, jardins, zones urbaines.  
*Sources : birdlife-psittacus-erithacus ; adw-psittacus-erithacus.*

## Régime alimentaire

Herbivore : surtout noix et fruits (dont palmier à huile *Elaeis*), feuilles, écorce, fleurs ; aussi insectes. Sur le terrain : fruits et graines en petits groupes (≤ ~30).  
*Sources : birdlife-psittacus-erithacus ; adw-psittacus-erithacus.*

## Comportement

Très social ; dortoirs bruyants (matins/soirs) ; couples monogames à vie ; nid en cavité d’arbre (10–30 m) ; diurne. Cognition complexe documentée (mimétisme, apprentissage social).  
*Sources : birdlife-psittacus-erithacus ; adw-psittacus-erithacus.*

## Chant et vocalisations

Enregistrement XC1137653 (Antoine Ede — CC BY-NC-SA 4.0) : https://xeno-canto.org/1137653  
ADW : cris d’alarme, de contact, de mendicité alimentaire, agonistiques ; cohésion du groupe via cris de contact.  
*Sources : media-psittacus-erithacus-audio ; adw-psittacus-erithacus.*
