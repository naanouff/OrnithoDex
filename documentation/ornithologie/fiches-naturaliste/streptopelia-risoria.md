## Description

**Forme domestique** (Barbary / ringed turtle dove) du programme. BirdLife traite le taxon sauvage apparenté sous *Streptopelia roseogrisea*, évalué **Least Concern** (2018) ; population non quantifiée, commune à localement abondante ; tendance suspectée **stable**. EOO reproduction ≈ 11 000 000 km².  
*Sources : birdlife-streptopelia-roseogrisea ; nomenclature domestique/sauvage discutée dans la littérature (ICZN) — on ne tranche pas au-delà de ce qui est sourcé.*
