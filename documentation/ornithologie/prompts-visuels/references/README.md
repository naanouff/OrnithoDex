# Références visuelles

Assets de **validation** pour les prompts (illustration + 3D).

Protocole de génération / validation illustration : [plan-suivi-illustrations.md](../../../projet/plan-suivi-illustrations.md).

## Convention

| Fichier | Usage |
|---------|--------|
| `{slug}-illustration.jpg` (ou `.png` / `.webp`) | Illustration naturaliste validée (source / référence) |
| `{slug}-3d.glb` (ou `.gltf`) | Pilote modèle 3D texturé |

`npm run data:prompts` injecte les sections correspondantes dans `{slug}.md` si les fichiers existent.

Stockage **documentation uniquement** pour la passe illustration — pas encore `public/images/birds/`.
