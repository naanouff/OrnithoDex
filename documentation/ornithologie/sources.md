# Politique de sources

## Principe

Ce projet est **open source** et pédagogique. **Il est interdit d’inventer** des informations sur les oiseaux.

- Toute information hors identité programme doit être **sourcée**.
- La source est **visible** sur la fiche du naturaliste (app + Markdown).
- **Toutes** les sources du projet sont listées dans le [README racine](../../README.md) (registre public).
- Sans source fiable : champ **vide** ou mention « Non documenté ».

## Types de sources acceptées

| Type | Exemples | Condition |
|------|----------|-----------|
| Programme / réglementaire | Liste BAC PRO TCVA, arrêtés | Obligatoire pour identité |
| Cours / polycopié fourni | Supports enseignant | Citation précise + ajout README |
| Ouvrages | Guides ornithologiques | Auteur, titre, année, pages si possible |
| Sites institutionnels | Muséums, associations reconnues | URL stable, date de consultation |
| Médias | Photos, enregistrements | Auteur, licence, URL |

Sources non acceptées seules : rumeurs, forums non expertisés, « connaissance personnelle » non documentée, contenu généré par IA non vérifié.

## Processus d’ajout

1. Vérifier la source (fiabilité, licence pour les médias).
2. Renseigner le fait dans la fiche Markdown avec `sourceIds`.
3. Ajouter la référence complète dans le bloc Sources de la fiche.
4. **Mettre à jour le registre Sources du README racine**.
5. Noter l’enrichissement dans le journal si significatif.
