# Taxonomie du référentiel

Ordres et familles présents dans la liste BAC PRO TCVA (source `bac-pro-tcva-liste`).

## 1. Galliformes

| Famille | Espèces (aperçu) |
|---------|------------------|
| Phasianidés | Caille peinte de Chine, poule domestique |
| Odontophoridés | Colin de Virginie, colin de Californie |

## 2. Ansériformes

| Famille | Espèces (aperçu) |
|---------|------------------|
| Anatidés | Canard mandarin, canard carolin |

## 3. Columbiformes

| Famille | Espèces (aperçu) |
|---------|------------------|
| Columbidés | Colombes, tourterelles, pigeon biset |

## 4. Psittaciformes

| Famille | Espèces (aperçu) |
|---------|------------------|
| Psittacidés | Inséparables, perruches, amazones, jaco, etc. |
| Cacatuidés | Rosalbin, calopsitte, cacatoès |

## 5. Passériformes

| Famille | Espèces (aperçu) |
|---------|------------------|
| Sturnidés | Mainate religieux |
| Passéridés | Moineau doré |
| Ploceidae | Tisserin gendarme, euplecte ignicolore |
| Estrildidés | Diamants, astrilds, capucins, etc. |
| Viduidés | Combassou, veuves |
| Fringillidés | Serins, canari |
