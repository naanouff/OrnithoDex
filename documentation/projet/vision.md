# Vision

**OrnithoDex** — nom de code du projet (dépôt GitHub et projet Vercel).

## Problème

Les élèves de **seconde professionnelle** du BAC PRO **Technicien conseil vente en animalerie** (TCVA, module MP6 – Ornithologie) doivent mémoriser un référentiel d’espèces d’oiseaux de cage et de volière. L’apprentissage purement scolaire (liste, polycopiés) manque souvent d’entraînement interactif adapté au smartphone.

## Solution

Un site pédagogique **open source**, version numérique augmentée d’un jeu de cartes :

- Consulter une **collection** d’espèces (identité programme + fiche du naturaliste)
- S’entraîner via des **quiz** (photo, chant)
- Écouter des **échantillons sonores** lorsqu’ils sont disponibles
- Toujours voir **d’où vient l’information** (sources visibles)

## Public

- **Prioritaire** : élèves de **seconde pro** BAC PRO **Technicien conseil vente en animalerie** (TCVA), module MP6 – Ornithologie ; usage **smartphone portrait**
- Secondaire : autres niveaux du même BAC PRO, puis toute personne souhaitant apprendre ces espèces domestiques et de volière

## Principes

1. **Exactitude** — aucune information inventée ; sources obligatoires
2. **Transparence** — registre public des sources dans le README racine
3. **Mobile-first** — conçu pour le pouce, pas pour un dashboard bureau
4. **Progressivité** — identité programme d’abord ; enrichissement des fiches au fil des sources validées
